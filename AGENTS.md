# Agent guidance

## App messaging

Before changing website copy, App Store text, onboarding, About text, or app-purpose descriptions, read [MESSAGING.md](MESSAGING.md). It contains the approved positioning, brief next-release store copy, writing rules, and native-copy handoff. No em dashes. Keep descriptions short and focused on the main customer goal.

## Website work

For any website, marketing page, support/privacy page, icon, screenshot, or public website URL update, read [WEBSITE_MIGRATION.md](WEBSITE_MIGRATION.md) first. Follow its workflow from this app folder; the canonical public website is maintained in the sibling `brianrenshaw-app-site` repository. Preserve unrelated app work and existing project guidance.
